# UMBRA Android mockup

Early visual exploration generated with the built-in image generation tool. The screens are conceptual and include proposed UI behavior; they do not describe the current implementation.

## Generation prompt

Use case: ui-mockup
Asset type: early visual concept board for the native Android app UMBRA.
Primary request: Design three polished, believable native Android messaging app screens, side by side: Chats, Conversation, Add contact. This is a lightweight design exploration for an existing privacy-focused messenger, not an implemented app.
Composition: landscape high-resolution board, three equal full-height flat Android screen mockups, front-on, no perspective, extremely thin device outlines, generous equal gutters. Screens approximately 412 by 892 logical pixels. Warm off-white presentation background. Above screens a small elegant title "UMBRA / Android concept" and below each a short caption "01  Chats", "02  Conversation", "03  Add contact". Screens must be large and UI text clearly readable. No marketing slogans or decorative diagrams.
Style: convincing native Android Material 3 / Jetpack Compose aesthetic. Roboto-like typography; readable 16sp body, 28sp screen headings; coherent 8dp spacing, 24dp screen margins, 48dp touch targets. Charcoal #121715 background, slightly lighter #1D2521 surfaces, soft white main text, muted gray secondary text, restrained pale mint #B5DDC4 accent and dark green outgoing messages. Rounded rectangles and clean Material-style line icons. Flat fills, no neon, no glass, no gradients, no huge floating cards. Personal and calm. Abstract simple local avatar shapes, no people photos. Status bar at 9:41, small centered Android camera cutout, battery icon, Android gesture bar at bottom. No iOS controls.
