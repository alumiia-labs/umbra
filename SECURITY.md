# Security policy

## Report a vulnerability

Do not open a public issue for a vulnerability.

Use the private report form of this repository on GitHub: open the
**Security** tab, then select **Report a vulnerability**.

Include these items:

- The part of the specification or the file of the code.
- The steps that show the fault.
- The effect on a user.

## Scope

A report can be about the specification in `spec/`, the Rust crates, the
Android app, the deployment playbooks, or the web site.

## Supported versions

UMBRA is at version 0.x. Only the newest commit of the `main` branch gets
corrections.
